## 一个贯穿始终的原则

这七篇背后的共同立场：

> **把模型擅长的事交给模型，把模型不擅长的事交给代码。**

模型擅长：读懂一段文字在说什么、判断"这个能不能用"、把散乱信息整理成结构、按意图组织语言。

模型不擅长：精确计算、保持一致的数字、不遗漏清单项、记住"我说过不许写别的标段"。

所以你会看到这个项目里到处是同一个模式——**模型只输出结构化数据或判断结果，确定性的部分（计算、校验、过滤、渲染、去重）全部由程序做**。

这不是对模型能力的不信任，而是分工：让模型集中做它真正创造价值的那部分。
